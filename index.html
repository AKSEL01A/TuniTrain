Installation

Comment installer l'APK

1

Télécharger

Appuie sur "Télécharger pour Android" pour récupérer le fichier APK.

2

Autoriser la source

Android va demander d'autoriser l'installation depuis cette source : accepte dans les paramètres.

3

Installer

Ouvre le fichier téléchargé et appuie sur Installer. L'application est prête.
